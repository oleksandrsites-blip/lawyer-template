# Бриф: шаблон сайту-візитки адвоката

_Складено 25.11.2026 за підсумками сесії ресерчу. Повний ресерч: `docs/research.md`._

## Мета
Один дуже якісний шаблон сайту-візитки адвоката, який за 20–30 хв персоналізується під реального адвоката (ім'я, місто, практики, контакти) і відправляється як прототип у холодному повідомленні. Модель уже перевірена: шаблон detailingrv → персоналізація → продаж vndetail.com за 11 000 грн.

Чесність: клієнту кажемо «концепт сайту під вашу практику», ніколи «зробив з нуля». Після продажу шаблон справді індивідуалізується (палітра, шрифти, композиція, тексти, фото).

## Архітектура
- Чистий HTML/CSS/JS, без важких бібліотек. Ціль: < 300 КБ без фото, Lighthouse 95+.
- **Один код, 3 стилі через CSS-токени:** Editorial (світлий), Тиша (темний + золото), Бюро (білий + акцент). **Починаємо з Editorial.**
- **Персоналізація через один `config`** (ім'я, місто, практики з бібліотеки модулів, телефон, Telegram/Viber, адреса, рік початку практики, № свідоцтва, рада адвокатів, ціна консультації, стиль).
- **Бібліотека модулів-практик** (тексти вже вичитані за етикою): військове, сімейне, кримінальне, ДТП, спадкове, земельне, трудове, бізнес. Під адвоката 2–4. Першими робимо військове + сімейне.
- **Прототипи лідів:** один проєкт Cloudflare Pages, кожен лід на своєму шляху (`/ivanenko`), `noindex`. Видаляти через 2–3 тижні без відповіді.
- Мобайл-first. Кнопки «Подзвонити» / «Написати в Telegram» завжди під рукою на телефоні.
- Schema.org `Attorney` / `LegalService`.

## Візуальний напрямок (Editorial, затверджено 25.11)
Референси в `docs/refs/` + Behance:
- Meridian (`refs/meridian.jpg`): **основа.** Кремово-бежевий фон, серифні заголовки, спокійна преміальність, багато повітря.
- Robert: https://www.behance.net/gallery/244853333/Lawyer-Roberts-Landing-Page-Website-UIUX-Design. Беремо велике ім'я як графічний елемент, таблицю справ (назва / категорія / дата), процес на «доріжці». Не беремо: темно-зелену палітру (це для стилю «Тиша»), бейджі з відсотками.
- Alexander: https://www.behance.net/gallery/246894147/Lawyer-Alexanders-Landing-Page-Website-UIUX-Design. Беремо курсивні акценти в серифних заголовках, гігантське ім'я в герої. Не беремо: молоток (це атрибут судді, не адвоката), «Proven results».
- TrueNorth (`refs/truenorth.jpg`): пізніше для стилю «Бюро».

**Не використовувати:** Феміду, терези, молоток, темно-синій із золотом, стоки з рукостисканням, CAPS LOCK. Класичність передаємо типографікою, фактурою мармуру чи паперу, архітектурним кадром, чорно-білим фото самого адвоката.

**Шрифти з кирилицею:** Cormorant Garamond / Playfair Display (заголовки), Manrope (текст). Перевіряти кирилицю у кожного шрифту.

## Структура (одна сторінка)
1. Хедер: ім'я, «Записатись на консультацію», телефон.
2. Герой: справжнє фото, ім'я великим, «Адвокат · місто · 2–3 практики», людяний рядок, CTA.
3. З чим звертаються: 3–6 карток **ситуацій** («Отримали повістку», «Розлучення і діти»), а не галузей права.
4. Як я працюю: 4 кроки.
5. Про мене: факти (рік практики, свідоцтво, рада адвокатів, освіта) + коротка людська історія.
6. Вартість консультації: прозоро, офлайн / онлайн.
7. Справи (знеособлено, таблицею в стилі Robert): ситуація → що зробили, без обіцянок.
8. Відгуки: з Google Maps з посиланням на оригінал.
9. FAQ: 5–6 справжніх питань клієнтів.
10. Контакти: карта, години, Telegram/Viber, форма на 2 поля (заявка йде в Telegram-бот).
11. Футер: № свідоцтва, примітка про адвокатську таємницю, «Сайт: oleks_web».

## Етика (ст. 13 Правил адвокатської етики): обов'язково
Не можна: оціночні характеристики («найкращий», «досвідчений»), гарантії й відсотки успіху, критика колег, загальні риси адвокатури як особливість саме цього адвоката. Замість цього факти: роки, номер свідоцтва, процес, ціна. Таблиця «не пишемо → пишемо» є в `research.md`, розділ 3.

## Процес
- Скіл `/new-site`, режим прототипу для холодного ліда (але як шаблон з конфігом).
- По 2–3 блоки за ітерацію з показом. Перевірка на 1440px і 375px.
- Пуш тільки після «ок» Олександра.
