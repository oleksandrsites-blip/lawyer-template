# /lead — прототип під адвоката за один захід

Олександр нічого не збирає руками. Він дає ліда (номер рядка, ім'я, посилання) — ти робиш усе нижче і в кінці показуєш результат + готове повідомлення.
Можна кілька лідів за раз (`/lead 3, 5, 8`): роби по черзі, звіт — один спільний.

Довідка по полях і командах: `docs/config.md`. Етика й заборони: `docs/brief.md` (розділ «Етика»). Більше нічого не перечитуй без потреби — економ токени.

## 1. Дані ліда
- Таблиця: https://docs.google.com/spreadsheets/d/1mJCWds_wbqy_hYF29HwYGmajBTHToPqUaN7TNlK2WZM/edit, аркуш «Адвокати». Прочитай рядок заголовків і потрібний рядок (Google Sheets connector).
- Відкриті джерела, 2–4 запити, не більше:
  - посилання з таблиці (OLX-оголошення/профіль): практики, формулювання, ціна, фото;
  - **ЄРАУ** (erau.unba.org.ua, пошук за ПІБ): № свідоцтва, дата, рада адвокатів — це факти для блоку «Про мене»;
  - Google Maps / власна сторінка, якщо є: адреса офісу, години, відгуки (лише реальні, з посиланням).
- Не знайшов — не вигадуй. Поле лишається з правдоподібним значенням і йде в `placeholders` (на сайті підкреслене пунктиром).

## 2. Фото
- Виклик `/lead` — це дозвіл завантажити **публічне фото профілю цього адвоката** (OLX/Maps/сайт) у scratchpad. Інших файлів без питання не завантажуй.
- `python3 tools/photo.py <slug> <файл>` → вирізає фон, робить ч/б. Подивись результат (Read на `public/img/leads/<slug>/cut-700.webp`).
- Фото нема, воно погане (обрізана голова, кілька людей, низька якість, логотип) — `"photo": null`: шаблон покаже монограму. Не став чуже чи стокове фото під справжнє ім'я.

## 3. Config і тексти
- `cp leads/demo.json leads/<slug>.json`, slug — прізвище латиницею (`ivanenko`; при збігу — `ivanenko-rivne`).
- `concept_note: ""` — без плашки зверху (вона ховає перший екран). `noindex: true`. `font: "onest"`, `font_switcher: false`.
- `title`: як людина називає себе сама (Адвокат / Адвокатка). Тексти шаблону в теперішньому часі — нейтральні до роду, але перевір свої вставки.
- `practices`: 2–4 модулі з `practices/`, що збігаються з тим, що адвокат реально пише про себе. Потрібного модуля нема → створи новий файл у тому ж форматі (4–6 ситуацій не треба: 3 досить), тексти — лише загальні кроки, без обіцянок. Скажи Олександру, що додав новий модуль. Ситуацій разом має бути 6 (сітка по 3): зайві ховай через `skip_situations`.
- `hero_line`, `about`: перепиши під людину з її власних формулювань (OLX-опис). `about_example: true`, якщо історія вигадана за зразком.
- **Ст. 13 Правил адвокатської етики:** жодних «найкращий», «досвідчений», «гарантую», відсотків успіху, критики колег. Лише факти: роки, свідоцтво, процес, ціна.

## 4. Збірка і перевірка
- `python3 build.py <slug>` → `public/<slug>/index.html` (+ OG-картинка для прев'ю посилання).
- Прев'ю: сервер `python3 -m http.server 8080` з папки `public/` (лаунчер прев'ю не має доступу до Documents — запускай через Bash у фоні, потім preview_start `lawyer-template`).
- Перевір на **1470×800** (MacBook Олександра), 1280×720 і 375 **лише** перший екран, «Про мене» і контакти: довге ім'я/практики не ламають рядки, голова на фото не обрізана, нема горизонтального скролу.
- **Перший екран = рівно один екран.** Картка hero займає вікно від меню до низу (невелике поле знизу), контент по центру, без гортання до статистики — і не стиснута до дрібної, щоб показати наступний блок. Перевір JS-ом: `.hero__card` bottom ≈ `innerHeight − 20`, `.hero__content` усередині картки. Розміри — від висоти екрана (svh) у `public/css/style.css`, не став фіксовані. Не влазить (довгий `headline`) — скороти текст, а не CSS. Знайдене — виправ до показу.
- Локальний коміт: `Лід: <Ім'я Прізвище>`. **Не пушити** — пуш один, пачкою, після «ок» Олександра.

## 5. Повідомлення адвокату
Посилання: `<BASE_URL з build.py>/<slug>/`. Формат — 4–6 рядків, на «ви», від імені Олександра, українською:
- привітання + одна конкретна деталь про цього адвоката (практика, місто, як працює — з джерел, не вигадана);
- що зробив концепт сайту саме під його практику, посилання, «краще дивитися з телефона»;
- одна фраза-цінність: тексти написані з урахуванням ст. 13 Правил адвокатської етики; заявки з форми приходять у Telegram;
- легке питання в кінці.

Заборонено: слово «шаблон», ціна, критика («у вас нема сайту — це погано»), вигадані факти, пафос, більше одного емодзі.
Додай нагадування на +3 дні з чимось новим (не «чи глянули ви»).

## 6. Звіт Олександру
Коротко, по кожному ліду: посилання (локальне + майбутнє), що знайшов у джерелах, що лишилось умовним (`placeholders`), повідомлення + нагадування. Таблиця — мінімальна, без довгих текстів (повідомлення й нотатки — лише в чаті). У рядок ліда пиши тільки:
- `Ім'я` (Ім'я Прізвище), `Місто`, `Практика` (2–3 слова: «Сімейне, мобілізація»);
- `Контакт` і `Прототип` — формулою `=HYPERLINK("url";"@нік")` / `=HYPERLINK("url";"/slug")` (локаль uk_UA, роздільник `;`);
- `Статус` → «Прототип готовий». `Надіслано` заповнює Олександр, `Фолоу-ап` рахується сам (+3 дні).
Значення, що починаються з `+` чи `=`, як текст не пиши — Sheets сприйме їх як формулу.
